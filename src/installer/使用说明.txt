KM减面大王 {{VER}}（ZBrush 2024 / 2026 插件）
==========================================

一个比 ZBrush 自带“减面大师”（Decimation Master）快很多的多线程减面插件，另外带一个“重拓扑并投射”按钮。
目前还是测试版，用之前请先保存工程。

适用：Windows 10 / 11 64 位，ZBrush 2024 或 2026。


一、安装
--------
1. 先保存并关闭 ZBrush。
2. 双击“安装.bat”。会弹出管理员权限提示，点“是”（ZBrush 装在 Program Files 里时需要）。
3. 窗口里会列出找到的 ZBrush 插件目录，输入编号回车（装多个就用逗号分开，比如 1,2）。
   没找到的话输入 M，再填 ZBrush 的文件夹。ZBrush 2026 要填“资源目录”，就是里面有 ZStartup 文件夹的那个。
4. 打开 ZBrush。第一次启动会自动编译插件，稍等一下；之后在 Zplugin 菜单里能看到 KM Decimate（按钮是中文）。
   如果没出现：ZScript > Load，选 ZStartup\ZPlugs64\KMDecimate.txt 编译一次。
   这会清空画布，但模型还在 Tool 面板里，选中它再按 T 回到编辑模式就行。

重新安装或升级：直接再运行一次“安装.bat”，旧版本会自动备份到 ZBrush 文件夹里的“KMDecimate备份_日期”。
卸载：双击“卸载.bat”。

杀毒软件：KMDecimate.exe 是自己编译的程序，没有数字签名。360 之类的软件第一次运行时可能会拦截或扫描几十秒，
请选择“允许”或把 ZStartup\ZPlugs64\KMDecimate 文件夹加入信任。插件会等它最多 2 分钟。


二、减面
--------
选中要减面的子工具，设置好下面几项，点“减面”。

- 保留百分比：保留原来三角形数量的百分之几，0.1–100。10 就是减到十分之一。
- 保留组边界：默认开，尽量不让 Polygroup 的边界变形。
- 保留顶点色：默认开。颜色边界附近（眼睛、描线、花纹）多留面，Polypaint 保持清晰，结果带 Polypaint；
  关掉时只按形状减，结果不带颜色。
- 颜色细节：1–10，默认 8，保留顶点色时才有用。数值越大，越多的面让给颜色边界，细线越清楚，
  但平的、单色的地方面会更少、形状误差稍大；1 = 形状优先。
- 保留原物体：默认开。开着时先复制一份再减，结果放在原物体下面，名字是“原名_KM百分比”；
  关掉时直接减当前子工具（有细分级时仍然会复制，因为原地删掉低细分级没法撤销）。

计算时 ZBrush 底部会显示进度：读取模型 / 准备中 / 正在减面 xx% / 写出结果。
这时按 Esc 可以取消，复制出来的副本会被删掉，模型不变。
导出和导入两步是 ZBrush 自己在做，这两步不能取消。
做完会弹窗显示导出、计算、导入各用了几秒。

现在还不支持：
- 不保留 UV；
- 不保留遮罩（Mask）。
需要这些的模型请继续用减面大师。


三、重拓扑并投射
----------------
一个按钮完成：把当前状态存起来 → ZRemesher 到目标面数 → 自动细分 → 每一级都把原来的细节投射回来。

- 目标多边形数：ZRemesher 的目标面数，单位千（5 = 5000）。
  ZRemesher 的其他选项（KeepGroups、Adapt、AdaptiveSize 等）沿用 Tool > Geometry > ZRemesher 里的设置。
- 细分级数：0 = 自动，选出让最高级面数最接近目标的级数，最多 8 级；1–8 = 固定细分这么多级。
- 目标面数(万)：自动细分时最高级要接近的面数，单位万；0 = 接近原模型最高级的面数。
- 预减面(万)：默认 100。ZRemesher 之前先把副本减到这么多万个三角形，高面数模型上 ZRemesher 会快很多；
  细分后的细节仍然从原模型投射回来。0 = 不预减面。用历史投射时不预减面。
  预减面这一步可以按 Esc 取消，整个重拓扑都会取消，模型不变。
- 用历史投射：
  · 关（默认）：先复制一份当作投射源，在副本上 ZRemesher、细分，每一级用 ProjectAll 投射。
    投射参数（Dist、Mean、PA Blur、Farthest 等）沿用 Tool > SubTool > Project 里的设置，
    投射时会临时隐藏其他子工具，结束后恢复。
    “保留原物体”开着：原模型保留并隐藏，结果叫“原名_ZR”；关着：投射完删掉原模型，结果改回原名。
  · 开：原地操作，用 ZBrush 自带的 Project History 逐级投射，省内存，但不能保留原物体。
    按按钮之前，要先在 ZBrush 的时间轴（Timeline）上 Ctrl+点击当前状态，记下一个历史点。

ZRemesher、细分和投射是 ZBrush 自己在算，不能用 Esc 取消，只会在底部显示进行到第几级。
做完的弹窗会列出每一步（复制、预减面、ZRemesher、细分并投射等）各用了几秒。


四、检查更新
------------
点面板最下面的“检查更新”（需要联网）。插件会去 GitHub 查最新发布的版本，几秒内弹窗告诉你结果：
有新版本时点“是”会打开下载页面，下载新的安装包，关掉 ZBrush 再运行一次“安装.bat”就行。
弹窗说连不上时，检查网络或代理；也可以直接打开 https://github.com/chankamman-dev/KMDecimate/releases 看。


五、文件位置
------------
- 插件：ZStartup\ZPlugs64\KMDecimate.txt 和 KMDecimate 文件夹。
- 设置和临时文件：C:\Users\Public\KMDecimate\
  减面的模型交换文件用完会自动删除。重拓扑会在 work 文件夹里留下最近一次的结果模型（zr_*.GoZ），
  供对比用，不需要时可以删掉。
- 出问题时请把 C:\Users\Public\KMDecimate\work\log.txt 发给作者。
